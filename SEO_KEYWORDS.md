# Cuelara SEO Keyword Strategy

This file contains the primary, secondary, and long-tail SEO keywords we must naturally integrate into our page titles, headers (H1/H2), meta descriptions, blog posts, and cookbook entries during development.

## 🎯 Primary Keywords (Core Identity)
*These should be present on the homepage and main navigation.*
- AI Prompt Optimizer
- Prompt Debugger
- Token Reducer
- Prompt Engineering Toolkit
- Best AI Prompts
- AI Prompt Formatter

## 💰 Token Optimization (Our Unique Selling Point)
*These target developers and power users looking to save API costs.*
- Token Saver
- Reduce AI Token Usage
- Lower OpenAI API Costs
- Token Estimator Tool
- Optimize Prompts for Token Efficiency
- Concise AI Prompts

## 🛠️ Model-Specific Keywords

- Grok Prompt Structure

## 🧠 The "Cookbook" & Content Keywords
*These target our educational content and templates.*

- Prompt Templates for Developers

## 📝 Development Guidelines for SEO
1. **Semantic HTML:** Always use proper `<header>`, `<main>`, `<article>`, and nested `<h1>` -> `<h2>` -> `<h3>` tags.
2. **Alt Text:** Every image must have descriptive `alt` text using these keywords where natural.
3. **Internal Linking:** Use these keywords as the anchor text when linking between the Blog, Cookbook, and Tools. *(e.g., "Check out our [Prompt Debugger] to fix this...")*
4. **URL Slugs:** Keep URLs short and keyword-rich (e.g., `/tools/token-reducer` instead of `/tools/reduce`).
